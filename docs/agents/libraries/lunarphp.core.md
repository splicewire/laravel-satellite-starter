# lunarphp/core

Used only by the opt-in local marketplace example through `splicewire/laravel-beam-market`. The disposable composition selects2.0.0-alpha.6; it is an alpha catalog engine, not a production-readiness claim. Ordinary starter manifests do not adopt it.

Market extends Lunar's Product/ProductVariant; the host adapter supplies seller/actor authority, not replacement catalog models. Consult the installed package source at `vendor/lunarphp/core/src/Models/{Product,ProductVariant,Language,Currency}.php`, `src/FieldTypes/`, `src/Auth/Manifest.php` and `database/state/EnsureBaseRolesAndPermissions.php`. The source snapshot contains no bundled Markdown reference or test runner. Package metadata identifies the upstream as `lunarphp/core` and `https://lunarphp.io/`.

Storage belongs to Lunar migrations and native Beam table-ownership preparation. Never recreate its production tables from a test harness. Its post-migration staff state originally wrote stock integer-keyed Spatie models despite this host's configured UUID models. The guide records the exact local prerequisite patch; it is a disposable proof dependency, not an upstream release or shipping requirement.
