# Preview the native MDX roundtrip without importing

This dormant standalone example calls the already-locked free `Splicewire\Beam\Mdx\MdxBody::encode()` and `decode()`. It previews normalization; it never imports, renders, compiles or executes MDX. No Laravel application, environment, database, actor or global production binding is required. The real Illuminate container resolves `FrontmatterParser` during each native operation and the exact previous container instance is restored in `finally`, including exceptions.

Use an isolated installed starter with its declared dependencies. Resolve your own Herd executable explicitly, for example `PHP_BIN="$(herd which-php)"` if supported by your Herd installation, or supply its absolute PHP8.4 path. Set `XDEBUG_MODE=off`. All Composer preparation belongs to the supported isolated scratch workflow; do not install or run this proof against an owner host.

Select a real, owned parent directory without symbolic components. Preparation creates ONLY a previously nonexistent directory and copies the two authored sample fixtures. It refuses an existing directory; never use an owner checkout or content directory. The marker binds its real path, device, inode and current OS user, to prevent accidental use of another location. It is a teaching-fixture boundary, not authentication or a sandbox against a user who can forge local files.

```sh
XDEBUG_MODE=off "$PHP_BIN" examples/mdx-preview/prepare.php --root "$OWNED_PARENT/mdx-fixtures"
XDEBUG_MODE=off "$PHP_BIN" examples/mdx-preview/inspect.php --root "$OWNED_PARENT/mdx-fixtures" --file canonical.mdx
XDEBUG_MODE=off "$PHP_BIN" examples/mdx-preview/inspect.php --root "$OWNED_PARENT/mdx-fixtures" --file normalizing.mdx
```

The canonical fixture has flat scalar title/navOrder frontmatter and a body with leading/trailing blank lines. The normalizing fixture has the SAME exact body, quoted title, a comment, blank frontmatter line and CRLF fences. Expectations are independently authored in PreviewTest.php, not generated by the codec. Exit0 means actual byte equality; exit1 means frontmatter normalizes while body bytes are preserved and the second native roundtrip is stable. Exit1 is an informational difference, not invalid MDX. Both successful JSON outputs include actual input/output hashes, byte lengths, equality/content-preserved/stability, relative filename and escaped exact normalized source. JSON escapes control characters and HTML delimiters; do not evaluate the preview. Each says “No file or draft was saved.” There is no output-file/apply/overwrite switch.

Exit2 is a failed input/read/bootstrap/codec/invariant check: no successful preview on stdout. Inputs must be regular current-user files under the marked root, lowercase .mdx, within1MiB, validUTF-8, and no symbolic path components. Missing/outside/non-MDX/oversize/badUTF8/symlink/changed inputs refuse. The original path identity, mode, metadata and hash are re-read at the end. This observation is not atomic filesystem CAS or protection against every external-editor race. Codec/body/stability failure never becomes an empty successful read. The test-only codec/observer seams exist for failure controls; the CLI always uses the real native codec.

For focused tests, create a separate owned empty testroom and set MDX_PREVIEW_TEST_ROOT to its real path. Run the installed PHPUnit directly with vendor/autoload.php and examples/mdx-preview/PreviewTest.php; no application TestCase or DB reset. Tests preserve the prior real container, check native parser limits, and create their own disposable fixture children. Keep/reap them through your scratch ownership tooling.

## The codec boundary

Frontmatter is a flat scalar parser, not YAML or an MDX validator. Native decode normalizes quoting, comments, blank lines and fence line endings. Duplicate raw keys collapse to their last value; unsupported lines can be skipped. An incomplete opening block remains content. Authored key spelling such as navOrder survives roundtrip; parsed lookup fields separately canonicalize to nav_order. Byte equality and second-roundtrip stability do not prove valid/safe code, MDX semantics, renderability, stable TSX node identity, admissible import, placement or publication. This example does not provide generic Files MDX support.
