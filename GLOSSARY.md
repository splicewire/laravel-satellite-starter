# splicewire/laravel-beam-starter

Language for the starter's setup and examples.

## Language

**Setup command**:
the one command a reader runs on a fresh copy of a starter to reach a
working host with its examples in place. A docs page asks for nothing beyond it.

**Example**:
a feature a starter ships already declared, wired and seeded, which the setup
command brings up and a chapter explains.
